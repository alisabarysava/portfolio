# AGENTS.md — правила для ИИ-агентов в этом проекте

Портфолио-сайт: статичный MPA, без сборщиков и фреймворков.
Владелец — дизайнер, не разработчик. Любые изменения — только по задаче,
без "улучшений" по собственной инициативе.

## Структура
- index.html, work-cases.html, concepts.html, 404.html
- cases/*.html — страницы кейсов
- css/main.css — единственный файл стилей
- js/main.js — основной скрипт; js/config.js — пароль
- assets/img/… — изображения; не удалять и не перезаписывать без явной задачи

## Workflow
1. Каждый файл читается максимум один раз за задачу.
2. Правки — точечные (replace_in_file); не переписывать файлы целиком.
3. Трогать ТОЛЬКО файлы, явно указанные в задаче.
4. Новый CSS — дописывается в конец main.css отдельной секцией;
   существующие правила не менять без прямой команды.
5. Ответ — только список изменённых файлов или короткое саммари.

## Дизайн
- Не выдумывать hover, цвета, тени, анимации: только по макету Figma
   или существующей дизайн-системе. Сомневаешься — спроси.
- Кнопки: только .btn / .btn--primary / .btn--secondary / .btn--text / .btn--icon.
- Язык контента — английский.

## Критично (известные грабли)
- .eyes всегда должен иметь background-clip: padding-box —
   без него Chrome рисует квадратные "уголки".
- view-transition-name уникальны на странице: header,
   nav-active (только у .active), eyes.
- У всех img явные width/height; ниже первого экрана — loading="lazy".
- Сторонних библиотек нет, кроме canvas-confetti (CDN).

## Не трогать
- Папки portfolio-checkpoint-* вне проекта.
- Логику пароля (window.PORTFOLIO_PASSWORD, localStorage
   cases_unlocked_date) — только по явной задаче.
